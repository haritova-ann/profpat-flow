# Инструкция по работе с шаблонами документов

## Что такое плейсхолдеры?

Плейсхолдеры - это специальные метки в документе Word, которые автоматически заменяются на реальные данные при генерации документа.

Формат плейсхолдера: `${ИМЯ_ПЕРЕМЕННОЙ}`

## Как добавить плейсхолдеры в шаблон?

1. Откройте файл шаблона в Microsoft Word или LibreOffice Writer
2. Найдите место, где нужно вставить данные (например, ФИО пациента)
3. Вместо реальных данных напишите плейсхолдер, например: `${FULL_NAME}`
4. Сохраните документ

### Пример:

**Было:**
```
Пациент: Иванов Иван Иванович
Дата рождения: 01.01.1990
```

**Стало:**
```
Пациент: ${FULL_NAME}
Дата рождения: ${BIRTH_DATE}
```

## Доступные плейсхолдеры

### Данные пациента

| Плейсхолдер | Описание | Пример значения |
|-------------|----------|-----------------|
| `${CARD_NUMBER}` | Номер амбулаторной карты | 12345 |
| `${FULL_NAME}` | Полное ФИО | Иванов Иван Иванович |
| `${LAST_NAME}` | Фамилия | Иванов |
| `${FIRST_NAME}` | Имя | Иван |
| `${MIDDLE_NAME}` | Отчество | Иванович |
| `${BIRTH_DATE}` | Дата рождения | 01.01.1990 |
| `${GENDER}` | Пол | Мужской / Женский |
| `${SNILS}` | СНИЛС | 123-456-789 00 |
| `${DOCUMENT}` | Документ (тип, серия, номер) | Паспорт РФ 1234 567890 |
| `${PHONE}` | Телефон | +7 900 123 45 67 |
| `${EMAIL}` | Email | example@mail.com |
| `${ADDRESS}` | Адрес проживания | Красноярский край, г. Красноярск, ул. Ленина, д. 1 |

### Данные медосмотра

| Плейсхолдер | Описание | Пример значения |
|-------------|----------|-----------------|
| `${EXAM_DATE}` | Дата медосмотра | 30.04.2026 |
| `${EXAM_TYPE}` | Вид медосмотра | Периодический / Предварительный / Внеочередной |
| `${HAZARD_FACTORS}` | Вредные факторы | 3.1, 3.2.1, 4.1 |
| `${PSYCHIATRIC_EXAM}` | Необходимость психиатрического освидетельствования | Да / Нет |
| `${PSYCHIATRIC_FACTORS}` | Пункт психиатрического освидетельствования | 1.1 |

### Данные работодателя

| Плейсхолдер | Описание | Пример значения |
|-------------|----------|-----------------|
| `${ORGANIZATION_NAME}` | Название организации | ООО "Рога и копыта" |
| `${ORGANIZATION_DEPARTMENT}` | Структурное подразделение | Отдел продаж |
| `${POSITION}` | Должность | Менеджер |
| `${INN}` | ИНН | 1234567890 |
| `${OGRN}` | ОГРН | 1234567890123 |
| `${EMPLOYER_PHONE}` | Телефон работодателя | +7 900 123 45 67 |
| `${EMPLOYER_EMAIL}` | Email работодателя | company@mail.com |
| `${EMPLOYER_ADDRESS}` | Юридический адрес | Красноярский край, г. Красноярск, ул. Ленина, д. 1 |

## Важные замечания

1. **Регистр имеет значение**: `${FULL_NAME}` и `${full_name}` - это разные плейсхолдеры
2. **Пробелы**: Не добавляйте пробелы внутри плейсхолдера: `${ FULL_NAME }` - неправильно
3. **Формат**: Используйте только формат `${ИМЯ}`, другие форматы не поддерживаются
4. **Пустые значения**: Если данных нет, плейсхолдер заменится на пустую строку

## Проверка шаблона

После добавления плейсхолдеров:

1. Сохраните шаблон
2. Откройте систему в браузере
3. Перейдите к любому медосмотру
4. Нажмите кнопку генерации документа
5. Проверьте, что все плейсхолдеры заменились на реальные данные

## Пример готового шаблона

```
СОГЛАСИЕ НА МЕДИЦИНСКОЕ ВМЕШАТЕЛЬСТВО

Я, ${FULL_NAME}, ${BIRTH_DATE} года рождения,
проживающий(ая) по адресу: ${ADDRESS},
паспорт: ${DOCUMENT},

даю согласие на проведение медицинского осмотра ${EXAM_DATE}
в рамках ${EXAM_TYPE} медицинского осмотра.

Место работы: ${ORGANIZATION_NAME}
Должность: ${POSITION}

Дата: ${EXAM_DATE}
Подпись: _______________
```

## Техническая информация

Система использует библиотеку PHPWord для работы с документами.
Обработчик генерации: `/visit/print_document.php`

Если плейсхолдер не заменяется:
1. Проверьте правильность написания
2. Убедитесь, что используется формат `${ИМЯ}`
3. Проверьте, что в коде есть соответствующий `setValue()`
